# Объяснить понятие

Тема: `$ARGUMENTS`

Структура ответа:

1. **Одной фразой** — суть без жаргона.
2. **Аналогия из жизни** — офис, кухня, библиотека, почта… Подбери под опыт студента из `PROGRESS.md`.
3. **Как это выглядит на практике** — короткий пример (команда, prompt, файл).
4. **Почему это устроено именно так** — какую проблему решает, что было бы без этого.
5. **Частая путаница** — с чем это путают и чем отличается.
6. **Проверь себя** — один вопрос.

Термин оставляй на английском, перевод — один раз в скобках. Если тема из будущего модуля — дай краткий ответ и скажи, в каком модуле разберём подробно. Если не уверен в факте о Claude Code — скажи об этом и предложи проверить документацию.
