# Quiz по модулю

1. Модуль: `$ARGUMENTS` или текущий из `PROGRESS.md`. Вопросы возьми из раздела «Quiz» в `.teacher/rubrics/NN.md` и добавь 1–2 своих на применение («что ты сделаешь, если...»).
2. Задавай **по одному вопросу**, жди ответ. Не показывай правильный ответ до ответа студента.
3. После каждого ответа: ✅/⚠️/❌ + короткое объяснение *почему* правильный ответ именно такой. Частично верный ответ — уточняющий вопрос.
4. 6–8 вопросов: ~половина на понимание, ~половина на применение в реальной ситуации.
5. Итог: счёт, темы для повторения со ссылками на разделы README. ≥ 80% — модуль можно закрывать.
6. Запиши результат и слабые темы в `PROGRESS.md`.
