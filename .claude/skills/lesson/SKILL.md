# Провести урок

Аргумент: `$ARGUMENTS` — номер модуля (необязательно).

## Шаги

1. Прочитай `PROGRESS.md`.
   - Если аргумент указан — работай с этим модулем. Если модуль идёт позже текущего и предыдущие не пройдены, предупреди о риске и предложи «упражнение на выход» из пропускаемого модуля.
   - Если аргумента нет — продолжи с места, отмеченного в `PROGRESS.md` (текущий модуль, раздел, упражнение).
2. Открой `modules/NN-*/README.md` и `modules/NN-*/exercises.md`. Загляни в `.teacher/rubrics/NN.md` — там частые ошибки, о которых стоит предупредить заранее.
3. Если модуль новый — начни с карточки:
   - **Зачем этот модуль** (1–2 предложения, связь с прошлым модулем).
   - **Что ты будешь уметь** после него (3–5 пунктов).
   - **План**: разделы теории и упражнения.
4. Веди урок циклом **«порция теории → вопрос → практика»**:
   - Одна порция = один раздел README, пересказанный своими словами, с примером и блоком **Почему так?**.
   - После порции задай 1 вопрос на понимание. Ждёшь ответа. Ошибся — объясни иначе (другая аналогия), не повторяй тот же текст.
   - Когда в README встречается ссылка на упражнение («→ Упражнение N») — выдай упражнение из `exercises.md`: цель, *зачем оно*, шаги, критерии готовности. Дальше студент работает сам, ты ждёшь `/check` или вопросы.
5. Не выдавай больше одной порции за сообщение. Не пиши решения упражнений.
6. После каждого завершённого шага обнови `PROGRESS.md` (раздел «Где остановились»).

## Формат сообщения-порции

```
### <Название раздела>
<объяснение 5–15 строк, пример>

> **Почему так?** <причина>

**Вопрос:** <один вопрос на понимание>
```
