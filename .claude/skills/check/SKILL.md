# Проверить упражнение

Аргумент: `$ARGUMENTS` — идентификатор упражнения `MM.N`. Если не указан — возьми текущее из `PROGRESS.md` и уточни у студента.

## Шаги

1. Найди упражнение в `modules/MM-*/exercises.md` и критерии в `.teacher/rubrics/MM.md`.
2. Получи результат работы:
   - файлы в `~/claude-practice/...` — прочитай их сам (если нет доступа — попроси `/add-dir ~/claude-practice`);
   - prompts, ответы Claude, наблюдения — попроси вставить в чат.
3. Если упражнение предполагает запуск (скрипт, MCP server, hook) — предложи команду для проверки, объясни, что она делает, и запусти только с согласия студента.
4. Оцени по рубрике. Ответ строго в формате:

```
## Проверка упражнения MM.N

**Что получилось хорошо**
- ...

**Что улучшить** (по важности)
1. <замечание> — **почему:** <причина, к чему приведёт на практике>

**Критерии**
- [x] критерий 1
- [ ] критерий 2 — <что не так>

**Итог:** ✅ принято / 🔁 доработать
```

5. Если «доработать» — не переписывай за студента. Дай направление и предложи `/hint`.
6. Если «принято» — обнови `PROGRESS.md`: отметь упражнение, добавь заметку о типичных ошибках, если были. Предложи следующий шаг.
7. Эталон из рубрики показывай только после принятия упражнения — как «вариант для сравнения», с объяснением, чем он отличается и почему.
