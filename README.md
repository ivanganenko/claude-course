# Claude на практике

Курс по эффективной работе с Claude и Claude Code: от первого prompt до собственных skills, MCP servers и subagents.
Курс ведёт **агент-преподаватель** — Claude Code, запущенный в этой папке. Он объясняет теорию порциями, выдаёт упражнения, проверяет их и ведёт ваш прогресс.

**Для кого:** вы уверенно пользуетесь компьютером и немного знакомы с программированием, но не работали разработчиком.
**Формат:** 11 модулей, ~60% времени — практика. Один модуль ≈ 2–4 часа.
**Язык:** русский, термины — на английском (как в документации и интерфейсе).

## Программа

| # | Модуль | Что научитесь делать |
|---|--------|----------------------|
| 01 | Как работают LLM и Claude | понимать tokens, context window, ограничения модели и почему Claude ошибается |
| 02 | Установка и первые шаги в Claude Code | работать в терминале, управлять сессией и разрешениями |
| 03 | Prompt engineering: основы | писать ясные prompts: контекст, структура, примеры, формат |
| 04 | Продвинутые prompts и управление контекстом | декомпозировать задачи, планировать, экономить context |
| 05 | Работа с кодом вместе с Claude | разбираться в чужом проекте, чинить баги, писать тесты, использовать git |
| 06 | CLAUDE.md и память | настраивать «постоянную память» проекта |
| 07 | Skills | упаковывать повторяющиеся процессы в skills |
| 08 | MCP | подключать внешние инструменты и написать свой MCP server |
| 09 | Агенты и subagents | понимать agent loop, делегировать работу subagents |
| 10 | Hooks, permissions, headless, безопасность | автоматизировать и защищать рабочий процесс |
| 11 | Финальный проект | собрать свой набор инструментов под реальную задачу |

## Что нужно перед стартом

1. **Аккаунт Claude** с доступом к Claude Code (подписка Pro/Max/Team/Enterprise или API key).
2. **Claude Code.** Установка на Windows (PowerShell):
   ```powershell
   irm https://claude.ai/install.ps1 | iex
   ```
   macOS / Linux / WSL:
   ```bash
   curl -fsSL https://claude.ai/install.sh | bash
   ```
   Проверка: `claude --version`. Актуальная инструкция: https://code.claude.com/docs
3. **Git** (на Windows — [Git for Windows](https://git-scm.com/downloads/win): он же даёт Bash, который использует Claude Code).
4. **Python 3.11+** — нужен с модуля 05 (учебный проект) и 08 (свой MCP server).
5. Редактор кода — например, VS Code.

> Не страшно, если что-то из этого пока не установлено: модуль 02 проведёт вас через установку шаг за шагом. Модуль 01 можно пройти в обычном чате claude.ai.

## Как начать

```bash
git clone <url-этого-репозитория> claude-course
cd claude-course
claude
```

В открывшейся сессии напишите:

```
/lesson
```

Агент прочитает `PROGRESS.md`, познакомится с вами и начнёт первый модуль.

## Два терминала

С модуля 02 вы будете работать в двух окнах терминала:

| Окно | Папка | Зачем |
|------|-------|-------|
| **Учитель** | `claude-course/` | теория, задания, проверка |
| **Практика** | `~/claude-practice/` | здесь вы сами работаете с Claude Code над упражнениями |

**Почему так?** Claude Code автоматически читает `CLAUDE.md` и skills из текущей и родительских папок. Если делать упражнения внутри курса, ваша практическая сессия тоже станет «учителем», а ваши skills смешаются с учебными. Отдельная папка — чистый эксперимент.

Чтобы учитель мог читать вашу практическую папку и проверять работы, запускайте его так:

```bash
claude --add-dir ~/claude-practice
```

(на Windows PowerShell: `claude --add-dir $HOME\claude-practice`)

## Команды учителя

| Команда | Что делает |
|---------|-----------|
| `/lesson [NN]` | начать или продолжить урок (можно указать модуль) |
| `/check [MM.N]` | проверить упражнение |
| `/hint` | подсказка без готового решения |
| `/quiz [NN]` | проверочный опрос по модулю |
| `/progress` | показать прогресс |
| `/explain <термин>` | объяснить понятие простыми словами |
| `/review-prompt <prompt>` | разобрать ваш prompt |

Можно и без команд — просто пишите «давай дальше», «проверь», «не понимаю, что такое token».

## Структура репозитория

```
CLAUDE.md               инструкции агента-преподавателя
PROGRESS.md             ваш прогресс (ведёт агент)
modules/NN-*/           теория (README.md) и упражнения (exercises.md)
practice/               стартовые файлы для упражнений
.teacher/               эталоны и критерии проверки (для агента; лучше не подглядывать 🙂)
.claude/skills/         skills агента-преподавателя
.claude/settings.json   разрешения для сессии учителя
```

## Совет

Не стремитесь пройти курс быстро. Цель — чтобы вы через месяц сами делали то, что сейчас делает учитель: писали prompts, skills и подключали инструменты под свои задачи.
