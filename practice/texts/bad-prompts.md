# 5 плохих prompts

Для упражнений модуля 03. У каждого prompt — **ситуация** (что на самом деле нужно автору) и сам **prompt**, который автор отправил Claude.
Твоя задача — понять, почему prompt плохой, и переписать его так, чтобы Claude мог сделать работу с первого раза.

Компания «Полярная Сова» и все люди — вымышленные. Файлы, на которые ссылаются prompts, лежат рядом: `report.md`, `meeting-notes.txt`, `sales.csv`.

---

## Prompt 1. «Сделай получше»

**Ситуация:** аналитик подготовила черновик квартального отчёта (`report.md`). В пятницу его будет читать генеральный директор — у него 5 минут, его интересуют деньги, риски и решения, которые от него нужны. Аналитик хочет, чтобы Claude помог подготовить отчёт к этой встрече.

**Prompt:**

```
Сделай отчёт получше.
```

---

## Prompt 2. «Не делай ничего плохого»

**Ситуация:** менеджеру поддержки нужно ответить клиенту «Горный Ключ» (тариф «Премиум»), который два дня ждёт ответа. Компания признаёт проблему, с 1 ноября для Премиум-клиентов запускается отдельная очередь, а клиенту в качестве компенсации предлагают бесплатный месяц обслуживания. Письмо пойдёт от имени менеджера Павла.

**Prompt:**

```
Напиши ответ клиенту. Не будь слишком формальным, но и не фамильярным.
Не пиши длинно. Не извиняйся слишком много. Не обещай ничего лишнего.
Не упоминай, что у нас мало людей в поддержке.
```

## Prompt 3. «Всё в одну кучу»

**Ситуация:** после планёрки нужно получить список задач: кто, что и к какому сроку делает. Список будет разослан участникам.

**Prompt:**

```
вот заметки переведи в задачи планерка 1.10 сайт подрядчик молчит Тимур дожмёт
смета до пятницы Света тексты к 15-му потом сказала к 20 окт Паша очередь
для премиум к след планерке Марина бюджет и сделай красиво и ещё напиши кто
больше всех молодец на этой планерке
```

## Prompt 4. «Великий эксперт»

**Ситуация:** руководитель отдела продаж хочет понять по выгрузке `sales.csv` (продажи за сентябрь), какой менеджер и какой регион тянут результат, а где проблемы, — чтобы обсудить это на встрече с менеджерами.

**Prompt:**

```
Ты лучший в мире эксперт-аналитик с 30-летним опытом работы в Fortune 500.
Проанализируй файл sales.csv и скажи всё, что думаешь.
Будь кратким, но максимально подробным.
```

---

## Prompt 5. «Сразу всё»

**Ситуация:** отток клиентов вырос (см. раздел 4 в `report.md`). Руководитель хочет к следующей неделе несколько идей, как удержать клиентов, чтобы выбрать 2–3 и обсудить с командой. Бюджет на удержание пока не определён.

**Prompt:**

```
Придумай 10 идей для удержания клиентов, распиши по каждой подробный план
внедрения, посчитай бюджет, переведи всё на английский и сделай презентацию.
```
